# Wila email signature

The page people use to copy their Wila email signature:
https://heywila.github.io/signature/

- `index.html` is the page. Change the signature layout or the install steps there.
- `wila-logo.png` is the logo that every installed signature loads. Do not rename, move or delete it, or the logo disappears from everyone's emails.
- `wila-logo.svg` is the vector source of the logo.

A personal link can pre-fill the form, for example `#name=Ada%20Lovelace&title=Engineer`.
Optional: `&btn=Button%20text&url=https://...` adds a booking button.
